## Material and rights boundaries

All authored documentation uses CC-BY-SA-4.0. The directory database uses ODbL-1.0. Its offline validators use GPL. Space Grotesk retains original OFL-1.1 notices and font bytes. Official identity assets use the separate [VINASIG Brand Usage Policy](../../BRAND_POLICY.md), with no blanket software or Creative Commons artwork grant.

Each repository carries full standard text, LICENSES.md, README and contribution guidance, package/lockfile metadata, source-text provenance and a dated review. Web builds carry AGPL/CC texts, source directions and the brand policy. Shared snapshots carry the standard's own GPL/CC grants in every profile and do not silently relicense consumers.

The installed license checker rejects missing software grants, package/lockfile drift, changed legal text, missing primary-license provenance and mismatched published notices. Existing asset and snapshot gates remain required. Installer regressions cover every profile and preserve owner files when a license has been locally modified.

Inspection covered live GitHub contributor responses, Git author histories, baseline rights records, imported files, all resolved lockfile license metadata and installed notices where modern metadata was absent. Only the maintainer account was found as a human contributor in the reviewed histories. Dependency-update bots and third-party software are not assigned VINASIG copyright.

## Human review and future changes

Unphar contains a separate phar.js 1.8.0 reference archive with a MIT license file and ISC package metadata. Both are preserved and excluded from the new grant. Historical favicon/reference material is also excluded where new provenance was not established. Resolve those upstream and historical rights before independently reusing them. They are not part of the active website distribution.

No other blocking external-contributor consent issue was identified within the reviewed VINASIG-authored scope. Repository administration is not a substitute for legal title. New contributors, new datasets, a separately packaged integration library or new vendor/binary distribution require another scoped review. No incorporation, copyright assignment or trademark registration is asserted.

The organization's earlier dated audits and release tags are retained as historical evidence. Current grants are identified in LICENSES.md. User inputs and independent generated output do not inherit copyleft simply because they were processed.
