# Community conduct

This document governs collaboration between people. Agent operating rules live in the core policies.

Treat contributors respectfully, discuss specific behavior and evidence, and allow correction without harassment. Do not discriminate, threaten, expose private information or impersonate someone. Disagree with a proposal by explaining its effect and alternatives.

An agent does not have authority to speak for a person, enforce sanctions or contact another contributor unless explicitly delegated. Repository maintainers may moderate within their actual platform role. No named enforcement team is claimed; ask the repository owner for an appropriate private conduct-reporting channel when needed. GitHub's private vulnerability route is for security findings.

Report concerns privately where a real reporting route exists. Share only the information needed for review. Decisions should explain the conduct, relevant context and proportionate response, while protecting private information.
